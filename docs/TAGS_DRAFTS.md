# 记录标签与草稿

## 管理标签

家长登录后进入 **家长后台 → 标签**（`/app/manage/tags`），添加或移除常用标签，再点击“保存标签”。家庭成员打开记录编辑器时会读取本家庭的常用标签；编辑器中也可以为当前记录添加自定义标签。

常用标签最多 60 个，每个最多 20 字；一条记录最多贴 8 个标签。编辑器里添加的自定义标签属于该条记录，不会自动加入家庭常用标签。需要重复使用时，由家长在标签管理中添加。

移除常用标签只会移除之后的可选项，已保存的旧记录仍保留原标签，打开旧记录时仍可取消选择。常用标签随家庭主页资料包含在家庭完整备份中；它与公开主页的“兴趣标签”是两个独立字段。

## 找回草稿

登录后点击导航栏或首页的 **我的草稿**（`/app/drafts`）：

- **家庭空间的草稿**：在编辑器点击“存草稿”后保存，可在登录后的其他设备上继续编辑。
- **本设备的自动草稿**：包括未保存的新记录和已有记录的未提交修改，只保存在当前账号的当前浏览器中；清理浏览器数据或更换设备无法带走。离线记事的待带回草稿也会在这里提示。

点击草稿进入编辑器。若家庭空间已有更新的版本，页面会保留设备草稿并提供对照和选择，不会直接覆盖新版。已保存记录仅在内容等发生修改后生成新的设备草稿。

## 已部署站点升级

本次需要同时更新后台和前台。先按[部署文档](DEPLOY_TENCENT.md#9-已部署站点的版本更新与回滚)备份数据库、附件及配置；在生产环境更新到包含本功能的代码后，先执行：

```bash
NODE_ENV=production npm run db:migrate --workspace @mylife/cms
```

本次新增迁移 `20261029_021636_entry_tag_options`，为已有家庭初始化原来的六个常用标签，不修改已有记录标签。随后构建并重启后台，确认接口正常，再发布同版本前台。无需重新执行 `seed`，不要用开发模式的自动结构同步代替生产迁移。旧版完整备份没有常用标签字段时，恢复后使用默认标签。
