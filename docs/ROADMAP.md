# 逐项实施计划

按当前产品要求：照片和视频自动优化；孩子可直接保存和公开，无需家长审批。隐私只有“仅自己和家长可见”和“所有人可见（包括游客）”两种。

## 阶段 A：先完成手机记录

- [x] 独立前台 `apps/web` 与后台 `apps/cms`，统一 TypeScript 协议。
- [x] Payload 账号、孩子/家长角色与家庭访问边界。
- [x] 四种记录方式、设备自动草稿与家庭草稿。
- [x] 图片压缩、上传进度、失败重试、录音与附件。
- [x] 持久化视频处理队列、FFmpeg 转码、失败重试及原件清理。
- [x] 真实发生时间、补录、模糊日期、私人时间轴与内容筛选。
- [x] 保存后修改、原文保护、Payload 版本历史。
- [x] 默认仅自己和家长可见、孩子直接公开与立即撤回的服务端规则。
- [x] 公开快照 API、公开首页与游客可读的独立记录详情。
- [x] 家长后台删除闲置素材及关联记录、转码任务保护。

阶段 A 不含专用 AI 页面，也不使用假数据代替存储、上传或权限验收。正式上线与真实手机视觉/交互验收需要部署环境及设备。

## 阶段 B：公开网站与亲子协作

- [x] 个人资料、头像封面、个人首页模块与三套主题。
- [x] 对外成长时间轴、作品展厅与荣誉页。
- [x] 成长项目模型、主项目/多项目关联、相关记录。
- [x] 手机家长概览、记录、版本、素材、成员、主题与服务管理。
- [x] 并发编辑的原子冲突保护：数据库条件写入、事务内版本与关系、跨进程写锁重试。
- [x] 图片排序与封面、素材库复用及未关联素材清理。
- [x] 外部历史文字资料的 CSV / JSON 批量导入：家长预览、指定成员、查重、整批事务与默认私密；本站档案 ZIP 另有恢复工具。
- [ ] 可配置 S3/R2 存储适配器、远程持久化部署与运维监控。
- [x] COS 按记录创建日期存储附件，CDN 签名访问，旧素材迁移、清空及完整 ZIP 备份/预检/还原。

当前 Payload 家长后台已可管理记录、素材、成员和内容版本。公开由孩子或家长直接选择，不再设置审批工作台。

## 阶段 C：AI 与长期保存

- [x] 家长配置 AI 服务与数据处理授权，默认关闭。
- [x] 语音转写、三个标题建议、原意整理和并排差异对比。
- [x] 接纳建议生成新版本，原始录音与最初表达持续保留。
- [x] 全量 JSON / Markdown / 媒体 / 项目 / 版本 ZIP 导出。
- [x] 隔离环境完成档案恢复演练，提供重要素材保留原件策略和生产备份步骤。
- [ ] 生产环境定时异地备份与恢复演练。
- [x] 移动端安装入口、Web Manifest、离线文字外壳、设备草稿带回与更新前保留草稿。

三维世界、公开留言、排行榜、人格评价暂不进入 V1。

AI 的权限、密钥、请求与结果解析已用受控传输测试；尚未配置用户实际服务或执行付费调用。真机录音权限、生产备份和云平台发布另行验收。

2026-10-27 这轮的使用方法、本地调试和宝塔更新命令见 [Roadmap 迭代说明](ROADMAP_ITERATION.md)。离线外壳只缓存公共资源，家庭 API、私密页面、媒体与登录结果不进入缓存；离线草稿在联网登录后由用户手动带回并保存。
