# 逐项实施计划

以分享计划最后的两项修正为准：照片和视频自动优化；孩子可直接保存，家庭记录不经过家长逐条审批。公开到互联网另设授权流程。

## 阶段 A：先完成手机记录

- [x] 独立前台 `apps/web` 与后台 `apps/cms`，统一 TypeScript 协议。
- [x] Payload 账号、孩子/家长角色与家庭访问边界。
- [x] 四种记录方式、设备自动草稿与家庭草稿。
- [x] 图片压缩、上传进度、失败重试、录音与附件。
- [x] 持久化视频处理队列、FFmpeg 转码、失败重试及原件清理。
- [x] 真实发生时间、补录、模糊日期、私人时间轴与内容筛选。
- [x] 保存后修改、原文保护、Payload 版本历史。
- [x] 默认家庭私密、公开申请、家长预授权与撤回的服务端规则。
- [x] 公开快照 API 与公开首页基础外壳。

阶段 A 不含专用 AI 页面，也不使用假数据代替存储、上传或权限验收。正式上线与真实手机视觉/交互验收需要部署环境及设备。

## 阶段 B：公开网站与亲子协作

- [ ] 个人资料、头像封面、个人首页模块与三套主题。
- [ ] 对外成长时间轴、作品展厅、荣誉页与独立内容详情。
- [ ] 成长项目模型、主项目/多项目关联、相关记录。
- [ ] 专用家长审核工作台：固定申请快照、差异、意见、完整审批日志。
- [ ] 审核时锁定申请版本，审批与并发编辑的原子冲突保护。
- [ ] 图片排序与封面、批量历史导入、素材库复用及未关联素材清理。
- [ ] 可配置 S3/R2 存储适配器、远程持久化部署与运维监控。

当前 Payload 家长后台已可管理记录、素材、成员和内容版本，也可审批、设置孩子公开预授权。完整审核工作台与专门的审批事件审计仍属阶段 B。

## 阶段 C：AI 与长期保存

- [ ] 家长配置 AI 服务与数据处理授权，默认关闭。
- [ ] 语音转写、三个标题建议、原意整理和并排差异对比。
- [ ] 接纳建议生成新版本，原始录音与最初表达持续保留。
- [ ] 全量 JSON / Markdown / 媒体 / 项目 / 版本 ZIP 导出。
- [ ] 完整备份、恢复演练、重要素材保留原件策略。
- [ ] 移动端安装体验与离线应用外壳。

三维世界、公开留言、排行榜、人格评价暂不进入 V1。
