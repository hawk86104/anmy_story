# MyLife · 孩子的阳光手账

这是独立的视觉提案，不修改应用代码、不发布站点、不更改家庭数据。

以仓库 README、docs/ROADMAP.md、docs/ARCHITECTURE.md 和现有页面为依据。原产品计划分享链接本次无法读取，因此以仓库内规划为准。设计中所有昵称、记录、作品和统计都是示例内容。

## 视觉方向

奶油白纸张、乌萨奇黄、焦糖棕文字，辅以鼠尾草绿、八奇瓦蓝和吉伊粉。公开网站像一本晒着太阳的成长手账；记录空间像容易打开的小本子；家长后台保持清楚、紧凑。

- 品牌保留 `mylife / 成长手记`，增加兔耳与手账结合的图形标识。
- Banner、登录封面、空状态使用插画；文字区使用干净纸色，背景点缀控制在边缘。
- 公开前台提供 1440px PC 与 390px 手机画稿。孩子记录空间与家长后台提供手机画稿，家长后台不制作 PC 版。
- 中文使用清晰的无衬线字体，标题带圆润感；手写感仅用于小标签和插画。
- 正文不低于 16px；手机主要点击区域至少 44px；黄底按钮配深棕文字。
- 保留两种可见范围：仅自己和家长、所有人可见。选择公开即可保存，不设计审批、排行榜、公开留言或人格评价。

## 设计文件

- `page-map.md`：页面、阶段、PC/手机范围。
- `tokens.json`：色板与排版、间距、圆角约定。
- `assets/`：独立素材，含主 Banner、透明角色贴纸、作品示例和图形标识。
- `exports/`：页面与总览导出。
- `assets/prompts.json`：通过内置 image_gen 使用的完整提示词。
- `pen-nodes.json`：当前 Pen 原生画布、页面节点、共享组件与检查结果。
- `pages/`：准备阶段的 SVG 版式稿；最终视觉以 Pen 原生画布及其 PNG 导出为准。
